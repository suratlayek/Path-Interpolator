Geometric Path Processing
Made Simple

A Python-based GUI utility for processing geometric paths. Offset paths, interpolate points at fixed intervals, and visualize results instantly.

Download Installer (v1.0) Build from Source

Key Features

Path Offsetting

Expand or contract paths using a numerical offset via Shapely buffers to adjust geometric boundaries easily.

Interpolation

Generate precise points at a specific distance interval along the calculated path length automatically.

Live Preview

Visualize the original input vs. the interpolated results in real time.

How to Use

Follow these steps to process your coordinate data effectively.

Input Format

Your input file should contain space-separated X and Y values on each line:

0.0000 0.0000
10.0000 0.0000
10.0000 10.0000

Parameters

r (Interval) The desired distance between each interpolated point.
Offset Distance to push the path outwards (+) or inwards (-).
Generate Creates a new file with the _interpolated suffix and updates the plot.

Setup and Execution

This project uses uv for extremely fast, reliable dependency management.

# 1. Clone & Enter the repository
git clone https://github.com/suratlayek/Path-Interpolator
cd path-interpolator

# 2. Initialize & Sync dependencies
uv sync

# 3. Run the application
uv run main.py

For End Users (.exe)

If you are using the standalone executable version, no Python installation or environment setup is required. Just launch path-interpolator-v1.0.exe.

Note: You may need to click "More Info" -> "Run anyway" if prompted by Windows SmartScreen.
